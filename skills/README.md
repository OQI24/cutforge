# skills

Рабочие Agent Skills Cursor:

```
.cursor/skills/<skill-name>/SKILL.md
```

Эта папка — только указатель. Агент **не** грузит скиллы отсюда.

Перед скиллами смотри **`knowledge/`** (правило knowledge + skills first).
