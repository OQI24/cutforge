# Music — Epidemic Sound

Промпты и заметки для подбора музыки. Исходники треков в git не кладём — только название / ссылка / куда легло в таймлайне.

**Лимит Assistant: ≤1000 символов** (включая пробелы и переносы). Перед копированием проверить длину.

На черновом таймлайне музыки нет: речь + продуктовый B-roll. Bed — только если отдельно попросят, тихо (−16…−18 dB к VO).
