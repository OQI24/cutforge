# knowledge

База знаний cutforge: устойчивые, **не привязанные к одному ролику** договорённости команды.

Агент при работе с репозиторием обязан **сначала заглянуть сюда** (хотя бы в индекс и нужную статью), затем в `.cursor/skills/` — см. правило `skills-first`.

## Оглавление

| Документ | О чём |
|---|---|
| [project-layout.md](project-layout.md) | Архитектура папки проекта, как завести новый живой проект, что в git |
| *(дальше)* | ритм, звук, цвет, платформенные форматы — по мере накопления |

## Как пользоваться

**Монтажёр (руками):** читать `project-layout.md` при старте серии; не копировать фантомные шаблоны из `projects/`.

**Агент:** перед созданием папки проекта, экспортом `.drt`, сортировкой сырья или сценариями рилсов — открыть релевантный файл из `knowledge/`, потом скилл.

Сюда **не** кладём сюжеты конкретных роликов (Toyota, герои, тезисы интервью) — только `projects/<имя>/`.
